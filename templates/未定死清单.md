# 未定死点清单（模板）

> 每条 = 一个下游可能要猜的点。归口规则见 references/缺陷归因与回流.md。

| # | 位置（条目/段落） | 缺的是什么 | 来源（静态/裁判分歧/多跑分歧/下游追问） | 处理 |
|---|---|---|---|---|
| 1 | | | | 定死 / 显式留白 / 升判据 |

## 处理三选一（挂确认点时用选项卡）

**A 定死它** —— 什么时候选：你知道答案、或这是地基。代价：要花一轮把细节补进产出。
**B 显式留白** —— 什么时候选：这点不值得定死、下游自由发挥也没风险。代价：留痕「留白，接受」，出问题回看能查到。
**C 升判据** —— 什么时候选：这类缺口反复出现，说明判据包没覆盖。代价：要改判据包并注明改因。

选了会发生什么：

| | A 定死 | B 留白 | C 升判据 |
|---|---|---|---|
| 这个点以后还猜吗 | 不猜 | 猜，但已认 | 猜不猜取决于新判据 |
| 影响范围 | 本条 | 本条 | 以后所有同类 |
| 留痕 | 补进产出 | 清单标「接受」 | 判据包改因 |
