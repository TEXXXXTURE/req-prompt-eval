## 三、五处阈值校准（调前 / 调后 + 支撑样本）

### ① 对象类型判别线：`方法论特征词计数 ≥3` → **强信号（框架词）≥2，弱信号不触发**

| | 旧口径（v0.1.1） | 新口径（v0.2） |
|---|---|---|
| 判法 | 全部特征词计数 ≥3 | 拆成**强信号**（`模板/公式/填空/以下…用于/分类说明`）与**弱信号**（`示例/建议/你可以`）；**仅强信号 ≥2** 触发 |
| T06（真实方法论模板） | 计数 4 → 触发 ✅ | 强 3 / 弱 1 → 触发 ✅ |
| N28（构造探针：正常提示词含 5 个弱信号词） | 计数 5 → **误判为模板** ❌ | 强 0 / 弱 5 → 不触发 ✅ |

**结果**：误判方向修正；T06/T11 仍判「不打分」（回归见§四）。**未覆盖**：中文「示例/以下/你可以」密度极高的正常成品的极端样本未构造（见§七-4）。

### ② 跨模态判别线：保留 `计数 ≥3`，**修字面 bug**

旧 `udio` 子串会误匹配 `studio` / `Audio`。修正为词边界后重跑：P08（Suno 音乐块）仍触发（≥3），P04 陶瓷杯（含 `studio`）不再误触。

### ④ 独立参数行判定线：`命中数/分句数 < 0.6` → **去掉参数 token 后该行剩余可见字符 ≤15**

| 样本 | 旧口径读数 | 新口径读数 | 正误 |

### ⑤ 空词 / 反模式密度曲线：`max(0, 100 − 密度×10)` → **双档台阶**

**调后效果**：旧线性公式把 P12（3.89）压到 61.1、P24 一类正常正例压低（E2 §五-5）；新台阶让正例最高档（4.70）仍落 85 档≥70，反例最低档（20.83）落 ≤20 档=30<70 → **正反例在两条曲线上都能分开**。

## 五、5 项待人复核的裁决建议（供人工确认，本报告不擅自闭环）

> 以下每条给「**判过 / 判不过 / 判据要改**」+ 理由。判据未改前，脚本与包一律按现状记「待人复核」。

| 项 | 争议点 | **裁决建议** | 理由 | 影响面 |
|---|---|---|---|---|
| **T2 · 8.3** 段间连续 | 「同一 `product` 即连续」能否替代显式交接帧 | **判过 + 判据要改（加口径）** | 8.3 的判据目的是「跨段身份 / 场景 / 光线不漂移」；T2 三段共享同一 `product`、承接同一灯光（`hero key light`）与动作（旋转→拆分→重组），用**同一锚点 + 状态承接**已完成这件事。显式交接帧（`交接帧:`/`Continue from the previous stage:`）只是**实现路径之一**，不是必要条件——B·§2.5 也只说「一条紧凑行优先」，未强制交接帧词。建议补口径：**同一锚点主体 + 上段结束状态 = 下段开始状态（含光线/场景承接）即算连续**；缺承接的（N20 多镜头无锁定块）仍不通过 | 会同时放宽 N20 类：必须把「承接三要素」写进口径，否则放过无锁定块的多镜头 |
| **T3 · 4.3** 光学参数 | `shallow depth of field` 算不算 | **判过 + 判据不改（补一句「部分」档）** | 4.3 通过长这样**明列「景深」**（原文：`给出焦段 / 景深 / 机身胶片`）；`shallow depth of field` 是可见后果（背景虚化），不是装饰。倒序误判的根因是把关键词当「只写器材名不写后果」——`shallow DOF` 本身即后果 | 建议补：**只有景深方向 + 可见后果才算**；单写 `bokeh`（无方向无配对）记「部分」 |
| **T4 · 12.1** 参数 | 官方散文例无参数：扣还是记不适用 | **判据要改（加「无参数 = 不适用」）→ T4 记不适用** | 12.1 的判据价值是「参数给了没、给全没、自相矛盾没」，**B·§2.6 的硬失败只针对「参数写进正文」**，没有任何来源说「不写参数即扣分」；C 侧 Seedance 官方 example 本身无参数。现口径「不给任何输出参数却也没说明 → 不通过」把**官方优秀基准**判成了缺陷。建议：无参数槽 → 记 `—`（不进通过率，同对象类型的处理），只有「给了但给不全 / 自相矛盾」才不通过 | 风险：免罚「本该给参数」的提示词 → 建议把「视频应有画幅 + 时长」作为**分档栏提醒**（不进主分），由人在平台档决定是否采纳 |
| **T9 · 1.1** 身份锁定 | `原创角色A` 是锚定还是泛称 | **判据要改（新增「弱锚定」档）；本项按现口径记不通过，等口径拍板** | `原创角色A` 给了「唯一命名」但没有**任何视觉信息**，模型无法据此锁定主体 —— 语义上等价于 `a person`（1.1 不通过长这样）。**但它与 T3 的 `Character A/B` 是同一类**（T3 在 E 报告里被判 1.1 通过），两侧标准不一致 → 需一次拍板：**具名角色编号在无外观描述 / 无素材指代时 = 弱锚定（记「部分」，不通过率不计）**。若采纳，T3 与 T9 一并按「部分」处理 | T3、T9；另影响 1.2 参考素材型口径的边界（有素材指代时才算强锚定） |
| **T12 · 裁判 · 密度** | 长负面块算「稀释」还是「无空评价词」 | **判据不改（v0.1.1 补丁 5 已闭环）→ T12 记「密度维通过 / 卫生维不通过」** | 两个维度量的不是一件事：信息密度维问「有没有空词稀释」（负面块每项都在履职，**通过**）；11.6 卫生维问「负面块长度」（17 项，**不通过**）。v0.1.1 补丁 5 已写明「类内齐全不豁免卫生；两维独立报；总判以硬规则 11.6 为准」——本项的「矛盾」是**两维分开报的正确表现**，不是判据自相打架 | 无新增；建议在评分卡把「两维独立」印刷在 T12 一类样本旁边 |
