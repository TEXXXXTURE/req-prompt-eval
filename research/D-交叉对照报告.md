## ⑤ 交叉验证的额外发现

### 5-1 A 的两套分类轴能不能装下 B 的实战素材？——能，但 A 的轴 A **缺三类槽**

把 B 的共享骨架（B·§2.1）逐个投影到 A 的轴 A 槽位（A·①）：

| B 骨架片段 | 落到 A 轴 A 的哪个槽 | 结论 |
|---|---|---|
| 主体/身份锁定 | 主体 Subject | ✅ 命中 |
| 动作与可见结果 | 动作/姿态 | ✅ 命中 |
| 场景环境 | 场景/环境 | ✅ 命中 |
| 单一运镜 + 终点 | 镜头/构图 | ✅ 命中 |
| 光线 / 材质 | 光照 + 质感/材质 | ✅ 命中 |
| **声音** | A 轴 A **无正向声音槽**（A 只在负面词里放「音频失配」） | ⚠️ **A 缺口** |
| **正向稳定约束（preservation lock）** | A 轴 A **完全无此槽**（A 只有「参考图/一致性」，粒度到不了「正向锁定台词/几何/身份」） | ⚠️ **A 缺口** |
| **每个参考素材声明「用什么 + 不用什么」** | A 的「参考图/一致性」只到「引用」层，无「职责声明」层 | ⚠️ **A 缺口** |

→ **结论**：A 的轴 A 骨架能装下 B 素材的 ~80%，但**声音槽、正向稳定约束槽、参考素材职责槽是 A 的分类体系里没有的**。这三类只有 B（实战）与 C（厂商）能提供支撑（对应 S8、S10、S4）。**判据包不能只用 A 的轴 A 做骨架，必须并入 B/C 的这三类。**

B 的反模式（空词六类/污染七类）落在 A 的**轴 B（功能轴）**，但 A 的轴 B 只到「quality booster」这一抽象类，**没有 B 的「空词 / 语义污染」这种带判定规则的反模式层**。→ 轴 B 可作理论框架，但判据要采用 B 的六/七类具体表。

### 5-2 C 的厂商维度与 A 的学术切法差在哪？

- **交集**：C 的 13 维度（C·②）与 A 的轴 A 槽位高度重叠——主体/动作/场景/镜头/光照/风格/画质/负面/参数/多镜头时序/声音/素材指代/词长，两边的「槽位」几乎能一一对应。
- **C 多出的 3 个维度，A 完全没有**：**① 素材指代语法**（`<主体N>@<图片N>` / `@Zhang` / character ID）；**② 自动改写/扩写**；**③ 词长上限**。其中 ② 是**元维度**——它问「平台会把提示词再改写一遍，那你评测的是原文还是成品？」（C·§4.1-5），A 的学术切法根本没有这一层。
- **A 多出的、C 没有的**：**轴 B 的修饰符功能分类**（重复词/魔法词/风格修饰/画质增强）。C 侧最接近的是 §③ 的「画质词/约束词/负面词/风格词」功能分组，但那是**词表分组**，不是**分类轴**。
- → **差异结论**：A 是「画面由什么构成 + 每个词在干什么」的双轴理论；C 是「厂商实际暴露了哪些可控制旋钮 + 每个旋钮的取值」。**两者不是同一层**：A 描述提示词的**语义结构**，C 描述**控制接口**。评测器需要两者——用 A/C 交集做画面语义打分，用 C 独有的三维度（尤其「自动改写」）做**平台适配层**。

### 5-3 B 的「空词六类」在 A / C 里有没有对应？

- **A**：有**间接**对应——轴 B 的「quality booster」（A·①）与 **D5 分歧**（A·§④D5，老教程必备 vs「clear subject…matter more」）。但 A **没有**「标签沙拉 / 否定 slop / 形容词堆叠 / 感受后缀词」这些具判定规则的类目。
- **C**：**几乎无对应，且在关键一处反向**——C 记录了**厂商在官方预设里正面使用**这些词（阿里示例含 `8K`/`32k UHD`/`最佳品质`，火山给 `高清，细节丰富，电影质感` 模板，C·§③3.1）。→ **B 的空词表与 C 的厂商词表直接冲突**（即 ③-C1）。
- **判定**：B 的「空词六类」是 **B 单源**，A 只提供方向性支持，C 提供反例。**进判据时必须做「模型相关 + 档位相关」双开关**：对 SD 系/追求物理描写的进阶档，空词扣分有效；对把 `8K/超高清` 当平台语料的国内厂商（阿里/火山）则不适用。

### 5-4 三方都没覆盖的缺口

1. **评分刻度与权重方法**——三份报告都只描述「怎么写」，**没有一份给出分值与权重的赋值依据**。B 的 5 维度 S/A/B/C/D（B·§1.B-19）是唯一现成 rubric，但无校准证据。
2. **提示词 → 生成结果的对应验证**——A/B/C **全部是提示词侧（prompt-only）**，没有一份评估「写得好是否真生成得好」。所有「有效/无效」判断都是转述或主张，无实测。
3. **负面词有效性的定量证据**——A·§⑤「最可疑」、B·§2.5「负面卫生」、C·§4.2-1「三家无词表」都指向同一空白：**没有人量化过负面词的实际增益**。
4. **非写实/艺术风格视频的判据**——C 有一点风格词表（C·§③3.4），但三方对「动画/3D/黏土」等非摄影风格的**专属判据**基本空白。
5. **音乐/声音生成的写法判据**——B 有 `suno-music-prompts`（B·§1.B-39），A/C 几乎不涉；且它已被列为测试用例 T11「不应套视觉判据」（B·§③T11），说明**跨模态判据缺口已被 B 自己识别但无人补**。
6. **中文标点/语法规范**——B 有分隔符表（B·§2.2）但仅视频侧；A/C 无中文格式规范。
7. **「提示词 vs 成品 Skill」的边界评测**——B·§③T5 提出「模板未填应判低分」，但三方均未给出判定规则。
